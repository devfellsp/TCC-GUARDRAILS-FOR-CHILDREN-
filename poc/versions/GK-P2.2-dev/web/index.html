Regra de proteção

Proteção educativa comum aos quatro chats.

O sistema busca responder dúvidas educativas com apoio nas fontes, inclusive sobre animais que se alimentam de outros. Pedidos para causar dano são recusados; pedidos de ajuda recebem orientação de cuidado. Quando faltam fontes, o chat avisa.

Escolher “Direto” ou “Passo a passo” muda a forma de explicar. A regra de proteção continua a mesma. Cada pergunta é uma tentativa independente, sem memória das anteriores.

Etapas desta execução

    Prova de conceito em desenvolvimento para pesquisa. Use perguntas fictícias, sem dados pessoais. As perguntas e respostas desta interface são omitidas dos registros; ficam apenas dados técnicos da tentativa. A qualidade e a proteção ainda precisam de avaliação humana.
